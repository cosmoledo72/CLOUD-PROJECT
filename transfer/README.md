# Перенос CLOUD-PROJECT на другой аккаунт Claude

В этой папке — всё, чтобы продолжить работу над проектом с другого аккаунта Claude с того же места.

| Файл | Зачем |
|---|---|
| `PROJECT_INSTRUCTIONS.md` | Постоянные правила работы — вставить в инструкции нового проекта Claude |
| `MEMORY.md` | Что Claude знал о вас и проекте — передать в память нового аккаунта |
| `HANDOFF.md` | Технический контекст: состояние, открытые вопросы, среда разработки, тесты |
| `cloud-project.bundle` | Полная история git (41 коммит) — на диске проекта git нет |
| `dev-env/` | Скрипты запуска среды разработки и демо-данных в облаке Claude |
| `../docs/SPEC.md`, `PLAN.md`, `CHAT_LOG.md` | Техническое задание, план, история решений |

## Шаги

1. **Создайте проект** на новом аккаунте: claude.ai → Projects → New project, название «CLOUD-PROJECT».
2. **Инструкции проекта:** откройте `PROJECT_INSTRUCTIONS.md`, скопируйте текст под чертой и вставьте в поле Instructions проекта.
3. **Документы проекта:** загрузите в проект файлы `docs/SPEC.md`, `docs/PLAN.md`, `docs/CHAT_LOG.md` и `transfer/HANDOFF.md`.
4. **Память:** в настройках включите память (Settings → «Generate memory from chats»). В новом чате проекта приложите `MEMORY.md` и напишите: «Запомни это о мне и проекте».
5. **Компьютер:** откройте Claude desktop на этом компьютере под новым аккаунтом, начните задачу в проекте и подключите папку `D:\PROGRAMS\CLOUD-PROJECT`.
6. **Первое сообщение** новому Claude, например:
   > Продолжаем работу над CLOUD-PROJECT. Прочитай transfer/HANDOFF.md, восстанови код из transfer/cloud-project.bundle и среду разработки по разделу 4, прогони тесты и скажи, что готово к работе.

## Что не переносится

- Переписка в чатах старого аккаунта — её суть сохранена в `docs/CHAT_LOG.md` и `HANDOFF.md`.
- Документ Claude «Перенос CLOUD-PROJECT на другой компьютер» — при необходимости экспортируйте его со старого аккаунта (Markdown или Word) и положите рядом.
- Портал, Docker, база и файлы на компьютере не зависят от аккаунта Claude — ничего переустанавливать не нужно.
- Подписка: на новом аккаунте нужен тариф с доступом к проектам и desktop-приложению (Pro или выше).
